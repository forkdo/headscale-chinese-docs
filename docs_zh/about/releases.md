# 发布版本

所有 headscale 发布版本都可以在 [GitHub 发布页面](https://github.com/juanfont/headscale/releases) 获取。这些
发布版本提供了适用于各种平台和架构的二进制文件、适用于基于 Debian 系统的软件包以及源代码归档。容器镜像可以在 [Docker Hub](https://hub.docker.com/r/headscale/headscale) 和
[GitHub Container Registry](https://github.com/juanfont/headscale/pkgs/container/headscale) 获取。

headscale 发布版本的 Atom/RSS 订阅源可在 [此处](https://github.com/juanfont/headscale/releases.atom) 获取。

请查看我们的 [Discord 服务器](https://discord.gg/c84AZQhmpx) 上的 "announcements" 频道获取关于 headscale 的最新消息。
