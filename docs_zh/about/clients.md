# 客户端和操作系统支持

我们致力于支持所有提供操作系统和平台上的 [**Tailscale 客户端最近 10 个版本**](https://tailscale.com/changelog#client)。某些平台可能需要额外配置才能与 headscale 连接。

| OS      | 是否支持 headscale                                                                                      |
| ------- | -------------------------------------------------------------------------------------------------------- |
| Linux   | 是                                                                                                       |
| OpenBSD | 是                                                                                                       |
| FreeBSD | 是                                                                                                       |
| Windows | 是（参见 [文档](../usage/connect/windows.md) 以及您 headscale 上的 `/windows` 以获取更多信息）           |
| Android | 是（参见 [文档](../usage/connect/android.md) 以获取更多信息）                                             |
| macOS   | 是（参见 [文档](../usage/connect/apple.md#macos) 以及您 headscale 上的 `/apple` 以获取更多信息）        |
| iOS     | 是（参见 [文档](../usage/connect/apple.md#ios) 以及您 headscale 上的 `/apple` 以获取更多信息）          |
| tvOS    | 是（参见 [文档](../usage/connect/apple.md#tvos) 以及您 headscale 上的 `/apple` 以获取更多信息）         |
