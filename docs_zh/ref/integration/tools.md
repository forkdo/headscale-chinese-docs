# 与 headscale 相关的工具

!!! warning "社区贡献"

    此页面包含社区贡献内容。此处列出的项目并非由 headscale 作者维护，而是由社区成员编写。

此页面收集了与 headscale 相关的第三方工具、客户端库和脚本。

- [headscale-operator](https://github.com/infradohq/headscale-operator) - Headscale Kubernetes 操作器
- [tailscale-manager](https://github.com/singlestore-labs/tailscale-manager) - 动态管理 Tailscale 路由通告
- [headscalebacktosqlite](https://github.com/bigbozza/headscalebacktosqlite) - 将 headscale 从 PostgreSQL 迁移回 SQLite
- [headscale-pf](https://github.com/YouSysAdmin/headscale-pf) - 基于 Jumpcloud 或 Authentik 中的用户组填充用户组
- [headscale-client-go](https://github.com/hibare/headscale-client-go) - 用于 Headscale HTTP API 的 Go 客户端实现
- [headscale-zabbix](https://github.com/dblanque/headscale-zabbix) - 用于 Headscale 服务的 Zabbix 监控模板
- [tailscale-exporter](https://github.com/adinhodovic/tailscale-exporter) - 用于 Headscale 的 Prometheus 导出器，通过 Headscale API 提供网络级指标
